<h2>Cursor가 하는 일</h2>
<p>Cursor는 VS Code를 포크해 만든 AI 네이티브 코드 에디터입니다. 에디터에 AI를 추가하는 것이 아니라 AI를 중심으로 편집 경험을 처음부터 다시 만들었습니다. 워크플로의 모든 부분이 AI를 인식합니다. 자동 완성은 프로젝트의 패턴을 바탕으로 여러 줄의 코드를 예측하고, 채팅은 전체 코드베이스를 이해하며, Composer는 자연어 설명으로 여러 파일을 동시에 편집합니다. 2026년 현재 Cursor는 전문 개발자들이 가장 자주 추천하는 에디터가 되었습니다.</p>

<h2>테스트 내용</h2>
<p>6주 동안 매일 실제 프로젝트에서 Cursor를 사용했습니다. Next.js SaaS 애플리케이션, Python 데이터 파이프라인, 여러 저장소에 걸친 버그 수정, 평이한 영어 설명으로 새로운 기능을 구현하는 작업이 포함됩니다. GitHub Copilot, Claude Code, 수작업 코딩과 결과물의 품질을 비교했습니다.</p>

<h2>2026년 9월 이후 달라진 점</h2>
<p>세 가지 주요 업데이트로 Cursor는 처음 리뷰했을 때보다 훨씬 강력해졌습니다.</p>
<ul>
  <li><strong>Composer 1.5:</strong> 2026년 2월 출시된 Cursor의 자체 에이전트 모델입니다. 이전 버전보다 컨텍스트 인식이 좋아지고 환각이 줄어든 상태로 여러 파일 편집을 처리합니다.</li>
  <li><strong>에이전트 모드:</strong> AI가 다단계 접근 방식을 계획하고, 파일을 편집하고, 명령을 실행하고, 오류를 처리하며, 자율적으로 반복합니다. 만들고 싶은 것을 설명하면 Cursor가 테스트를 실행하고 문제를 고쳐 가며 직접 만들어 줍니다.</li>
  <li><strong>가격 변화:</strong> Cursor는 이제 Plus(월 $8)와 Premium(월 $30) 등급을 제공합니다. GitHub Copilot은 2026년 6월 사용량 기반 AI Credits 과금으로 전환하여 경쟁 구도의 계산이 달라졌습니다.</li>
</ul>

<h2>장점</h2>
<ul>
  <li><strong>코드베이스 인덱싱:</strong> Cursor는 모든 파일, 모든 import, 모든 타입 정의 등 프로젝트 전체를 인덱싱합니다. 기능 구현을 요청하면 프로젝트 구조, 명명 규칙, 기존 패턴을 알고 있습니다. 이는 각 제안을 더 독립적으로 다루는 GitHub Copilot에 비해 가장 큰 단일 이점입니다. 파일이 몇 개를 넘는 프로젝트에서 작업할 때 차이가 즉시 드러납니다.</li>
  <li><strong>Composer 다중 파일 편집:</strong> 원하는 것을 평이한 영어로 설명하면 Composer가 프로젝트 전반의 파일을 만들고, 수정하고, 연결합니다. "이메일과 비밀번호를 사용한 사용자 인증을 추가하고, 로그인 및 회원가입 페이지를 만들고, 기존 데이터베이스에 연결해 줘"라고 하면 Composer가 이를 분리된 개별 편집이 아닌 하나의 일관된 작업으로 처리합니다. 여러 파일에 걸친 리팩터링이나 기능 추가에서는 몇 시간을 절약해 줍니다.</li>
  <li><strong>에이전트 모드:</strong> Composer를 한 단계 더 발전시킨 기능입니다. 에이전트는 접근 방식을 계획하고, 단계를 실행하고, 테스트를 돌리고, 오류 메시지를 읽고, 반복합니다. 스택 트레이스가 포함된 버그 리포트를 건네면 문제를 찾아내고, 수정안을 제시하고, 구현하고, 테스트를 실행한 뒤 보고합니다. 주니어 개발자에게 맡길 만한 작업에 이 자율성은 정말 유용합니다.</li>
  <li><strong>Tab 자동 완성:</strong> 자동 완성이 단순히 타이핑하는 내용이 아니라 만들고 있는 것을 AI가 이해하는 것처럼 느껴질 정도로 맥락을 인식합니다. 프로젝트의 패턴을 바탕으로 함수 본문 전체, 테스트 케이스, API 핸들러 같은 여러 줄을 예측합니다. 테스트에서의 수락률은 약 45%로, 9월 리뷰의 40%에서 올랐습니다.</li>
  <li><strong>익숙한 환경:</strong> VS Code를 기반으로 하기 때문에 모든 확장, 테마, 키 바인딩, 설정이 그대로 옮겨집니다. VS Code에서 Cursor로 전환하는 데 5분도 걸리지 않습니다. 이미 VS Code를 쓴다면 에디터 자체에는 학습 곡선이 없고 AI 기능만 익히면 됩니다.</li>
</ul>

<h2>단점</h2>
<ul>
  <li><strong>사용 한도:</strong> Premium의 요청 한도가 헤비 유저에게는 제약이 될 수 있습니다. 복잡한 문제를 디버깅하거나 새 기능 모듈을 만드는 집중 개발 기간에는 하루 만에 한도에 도달할 수 있습니다. 코딩은 계속할 수 있지만 한도가 초기화될 때까지 프리미엄 AI 기능은 쓸 수 없습니다. Cursor 파워 유저들의 가장 흔한 불만입니다.</li>
  <li><strong>VS Code 전용:</strong> 팀이 JetBrains(IntelliJ, PyCharm, WebStorm), Neovim, Xcode를 쓴다면 Cursor는 선택지가 아닙니다. 이것이 GitHub Copilot이 어디서나 작동하기 때문에 68%의 시장 점유율을 유지하는 주된 이유입니다.</li>
  <li><strong>가끔 발생하는 환각:</strong> 에이전트 모드는 가끔 올바르게 보이지만 미묘한 버그가 있는 코드를 생성합니다. 잘못된 import 경로, 잘못된 API 메서드, TypeScript는 잡아내지만 동적 언어에서는 잡히지 않을 타입 불일치 같은 것들입니다. 생성된 코드, 특히 복잡한 로직은 검토가 필요합니다.</li>
  <li><strong>대규모 모노레포:</strong> 매우 큰 코드베이스에서는 성능이 저하됩니다. 인덱싱이 느려지고, 컨텍스트 윈도우가 가득 차고, 제안의 관련성이 떨어집니다. 수백만 줄 규모의 모노레포에서는 작은 프로젝트보다 경험이 눈에 띄게 나빠집니다.</li>
  <li><strong>문서화:</strong> Cursor의 공식 문서는 빈약합니다. 대부분의 팁, 워크플로, 모범 사례는 YouTube 영상, 트위터 스레드, 블로그 게시물 등 커뮤니티에서 나옵니다. 회사가 문서화하는 속도보다 기능을 출시하는 속도가 더 빠릅니다.</li>
</ul>

<h2>최종 평가</h2>
<p>Cursor는 AI 지원 코딩의 느낌을 근본적으로 바꿨기 때문에 <strong>A</strong>를 받았습니다. 코드베이스 인덱싱, Composer 1.5, 에이전트 모드는 가능한 일의 진정한 도약을 보여 줍니다. 기능을 평이한 영어로 설명하고 Cursor가 프로젝트 전반에 걸쳐 파일을 만들고, 로직을 작성하고, 컴포넌트를 연결하고, 테스트를 실행하는 모습을 지켜보는 경험은 몇 달간 매일 쓴 지금도 여전히 미래처럼 느껴집니다.</p>
<p>A+를 받지 못한 이유는 VS Code 한정(상당수의 개발자를 배제함), Premium의 사용 한도(집중 코딩 세션에서 파워 유저를 답답하게 함), 빈약한 문서 때문입니다. Cursor가 JetBrains 지원을 추가하고 사용 한도를 없앤다면 손쉽게 A+가 될 것입니다.</p>
<p>매일 코딩하는 VS Code 개발자에게 Cursor는 권장 수준이 아니라 필수입니다. 무료 요금제로 차이를 확인한 다음 한도에 도달하면 Premium으로 업그레이드하세요. 금방 한도에 도달할 것입니다.</p>

<h2>자주 묻는 질문</h2>

<h3>Cursor는 무료인가요?</h3>
<p>네, Cursor에는 제한된 자동 완성과 기본 채팅이 있는 무료 요금제가 있습니다. 월 $8의 Plus와 월 $30의 Premium은 더 많은 기능과 더 높은 한도를 제공합니다.</p>

<h3>Cursor가 GitHub Copilot보다 나은가요?</h3>
<p>VS Code 사용자에게는 그렇습니다. 더 깊은 코드베이스 인식과 더 나은 다중 파일 편집을 제공합니다. Copilot은 IDE 지원(40개 이상의 에디터), 넉넉한 무료 요금제(자동 완성 2,000회 $0), 네이티브 GitHub 통합에서 앞섭니다.</p>

<h3>Cursor에서 VS Code 확장을 사용할 수 있나요?</h3>
<p>네. Cursor는 VS Code를 기반으로 만들어져 모든 VS Code 확장, 테마, 키 바인딩을 지원합니다. 마이그레이션에는 5분도 걸리지 않습니다.</p>

<h3>Cursor는 월 $30의 가치가 있나요?</h3>
<p>전업 개발자에게는 충분히 그렇습니다. 다중 파일 작업, 리팩터링, 기능 구현에서 절약하는 시간으로 일주일 안에 본전을 뽑습니다. 가끔 코딩하는 사람에게는 무료 요금제나 월 $8의 Plus로 충분합니다.</p>

<h3>Cursor는 JetBrains에서 작동하나요?</h3>
<p>아니요. Cursor는 VS Code 전용입니다. JetBrains 사용자는 GitHub Copilot이나 JetBrains AI Assistant를 사용해야 합니다.</p>
