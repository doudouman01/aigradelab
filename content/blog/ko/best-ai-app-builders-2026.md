<h2>중요: AI 앱 빌더의 가능성과 한계</h2>
<p><strong>잘할 수 있는 것:</strong> 프로토타입 생성, CRUD 앱 구축, 랜딩 페이지 제작, MVP 검증, 표준 웹 앱 패턴 처리.</p>
<p><strong>아직 할 수 없는 것:</strong> 복잡한 엔터프라이즈 소프트웨어, 정교한 비즈니스 로직, 프로덕션 보안, 대규모 DB 관리. "처음 80%" 도구로 생각하세요.</p>

<h2>1. Bolt — 등급: B+</h2>
<p><strong>최적: 속도 — 가장 빠른 프로토타이핑</strong></p>
<p>Bolt은 속도 챔피언입니다. 1-3분 안에 풀스택 앱을 생성합니다. React 프론트엔드, Node 백엔드, DB, 배포 코드 포함.</p>
<h3>장점</h3>
<ul><li>가장 빠른 생성 시간</li><li>풀스택 출력</li><li>반복 편집 지원</li><li>직접 배포</li><li>무료 플랜</li></ul>
<h3>단점</h3>
<ul><li>코드 정리 필요</li><li>복잡한 로직에 버그</li><li>아키텍처 제어 제한적</li><li>사용량 과금 비쌀 수 있음</li></ul>
<p><strong>가격:</strong> 무료 / Starter $20/월. <strong>평결:</strong> 속도가 최우선일 때 최고의 선택.</p>

<h2>2. Lovable — 등급: B+</h2>
<p><strong>최적: 코드 품질 — 가장 깔끔한 출력</strong></p>
<p>Bolt과 경쟁하지만 코드 품질 우선. 더 깨끗하고 유지보수하기 쉬운 코드 생성.</p>
<h3>장점</h3>
<ul><li>가장 깨끗한 코드</li><li>더 나은 기본 UI</li><li>GitHub/Supabase 통합</li><li>개발자 인수인계 적합</li></ul>
<h3>단점</h3>
<ul><li>Bolt보다 느림</li><li>복잡한 앱은 개발자 필요</li><li>작은 커뮤니티</li></ul>
<p><strong>가격:</strong> 무료 / Starter $20/월. <strong>평결:</strong> 계속 개발할 계획이면 Lovable 선택.</p>

<h2>3. Replit — 등급: B+</h2>
<p><strong>최적: 올인원 — 브라우저에서 빌드, 실행, 호스팅</strong></p>
<p>AI Agent + 완전한 IDE, 터미널, DB, 호스팅을 브라우저에서 제공합니다.</p>
<h3>장점</h3>
<ul><li>완전한 환경</li><li>AI Agent 앱 생성</li><li>내장 호스팅</li><li>만들면서 배우기</li><li>큰 커뮤니티</li></ul>
<h3>단점</h3>
<ul><li>AI 품질 약간 뒤처짐</li><li>복잡한 프로젝트 성능 이슈</li><li>가격 복잡</li></ul>
<p><strong>가격:</strong> 무료 / Pro $25/월. <strong>평결:</strong> 코드를 직접 이해하고 싶다면 최고 선택.</p>

<h2>4. v0 by Vercel — 등급: B</h2>
<p><strong>최적: UI 컴포넌트 생성</strong></p>
<p>전체 앱이 아닌 개별 UI 컴포넌트를 생성합니다. shadcn/ui와 Tailwind CSS로 프로덕션 품질 React 코드를 생성.</p>
<h3>장점</h3>
<ul><li>최고 품질 UI 코드</li><li>업계 표준 스택</li><li>프로덕션 준비 완료</li><li>Next.js에 통합</li></ul>
<h3>단점</h3>
<ul><li>컴포넌트만</li><li>개발자 지식 필요</li><li>React/Next.js로 제한</li></ul>
<p><strong>가격:</strong> 무료 / Premium $20/월. <strong>평결:</strong> 개발자 전용 컴포넌트 생성기.</p>

<h2>5. Cursor + Claude Code — 등급: A (개발자용)</h2>
<p><strong>최적: 최고 품질, 최대 제어</strong></p>
<p>전통적 앱 빌더는 아니지만 많은 개발자가 AI와 함께 완전한 앱을 구축합니다. 모든 파일과 결정을 완전히 제어.</p>
<h3>장점</h3>
<ul><li>최고 코드 품질</li><li>완전한 제어</li><li>모든 프레임워크 작동</li><li>프로덕션 수준</li></ul>
<h3>단점</h3>
<ul><li>개발자 필요</li><li>느림</li><li>비쌈 ($50/월)</li></ul>
<p><strong>가격:</strong> Cursor $30 + Claude Pro $20 = $50/월. <strong>평결:</strong> 프로덕션 품질 필수 시 최고 옵션.</p>

<h2>자주 묻는 질문</h2>
<h3>코딩 없이 실제 앱을 만들 수 있나요?</h3>
<p>프로토타입은 가능합니다. 프로덕션 앱은 아직 아닙니다. AI가 80%, 개발자가 20%.</p>
<h3>Bolt vs Lovable?</h3>
<p>Bolt이 빠르고, Lovable이 깨끗합니다. 데모 급하면 Bolt, 계속 개발하면 Lovable.</p>
<h3>AI 앱은 안전한가요?</h3>
<p>기본적으로 아닙니다. 보안 수동 검토가 필요합니다.</p>
<h3>비용은?</h3>
<p>프로토타입 $0, MVP $20-25/월, 프로덕션 $50+/월 + 개발자 시간.</p>
