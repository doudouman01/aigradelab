<h2>Anthropicがコードエージェントを Claude Ship に統合</h2>

<p>2026年11月24日、Anthropicは<strong>Claude Ship</strong>を発表しました。これはコードが書かれた後のすべてのプロセスを処理するために設計された、統合AIエージェントセットです。既に一般提供されているCode Review機能と、現在ベータ版の2つの新しいエージェント——<strong>PR Steward</strong>およびリスクベースの<strong>自動承認システム</strong>——を1つのバンドルにまとめています。</p>

<p>このリリースは、AIコーディングツールの進化における転換点を反映しています。コードを書くことはもはやボトルネックではありません。コードをレビューし、修正し、デプロイすることがボトルネックなのです。</p>

<h2>Claude Shipの構成要素</h2>

<h3>1. Code Review（一般提供中）</h3>

<p>2026年3月にリリースされたCode Reviewは、すべてのプルリクエストにAIエージェントチームを投入します。エージェントは並列で動作し、バグの検出、誤検知の除外、問題の重大度によるランク付けを行います。Anthropic社内では、このツールにより実質的なレビューコメントがPRの16%から54%に増加し、エンジニアが誤りと判定した結果は1%未満でした。</p>

<p>レビューは複雑さに応じてスケールします。大規模または複雑なプルリクエストにはより多くのエージェントと深い分析が割り当てられ、軽微な変更は簡易チェックで済みます。平均的なレビューは約20分で、トークン使用量に基づき15〜25ドルが課金されます。</p>

<h3>2. PR Steward（新機能 — ベータ版）</h3>

<p>PR StewardはClaude Shipバンドルの2つ目の要素で、コードレビュー後に蓄積する煩雑な作業を処理します。PRにCIチェックの失敗、マージコンフリクト、未解決のレビューフィードバックがある場合、PR Stewardが自動的に修正に入ります。</p>

<p>プッシュのたびに、変更内容のサマリーとロールバック手順をPRにコメントします。これにより、PRがキューで滞留する原因となる手作業のオーバーヘッドを取り除きつつ、開発者がコントロールを維持できるよう設計されています。</p>

<h3>3. リスクベースの自動承認（新機能 — ベータ版）</h3>

<p>3つ目のコンポーネントは、段階的な承認システムを導入します。低リスクの変更——ドキュメントの更新、フィーチャーフラグ背後の内部機能——は、人間の承認が不要な場合があります。中リスクの変更には1人の人間レビュアーが必要です。高リスクの変更には2人が必要です。</p>

<p>AIエージェントの承認は、人間の承認の代わりにはなりません。このシステムは、重要な判断から人間の判断を排除することなく、安全な変更を加速するために設計されています。</p>

<h2>なぜ重要なのか：レビューのボトルネックは現実の問題</h2>

<p>Anthropicの社内データがその実態を示しています。Claude Codeのモノレポは、5月の1日あたり約2,500件のマージ済み変更から、2026年9月には30,000件以上に増加しました。現在、ClaudeはAnthropicのコードの約90%を書いています。その一方で、マージ済みプルリクエストが2倍以上に増えたにもかかわらず、リバート率は40%以上低下しました。</p>

<p>問題はもはやコード生成ではなく、その後のすべてのプロセスです。Claude Shipは、AIがコードを書く速度と人間がそれをレビューする速度の間の拡大するギャップに対するAnthropicの回答です。</p>

<h2>他のAIコーディングツールとの比較</h2>

<p>Claude Shipは、IDE内でのコードの記述と編集に焦点を当てた<strong>Cursor</strong>や<strong>GitHub Copilot</strong>とは異なるニッチを占めています。Shipはコーディング後のワークフロー——レビュー、CI修正、マージ承認——をターゲットにしています。</p>

<p>とはいえ、GitHubのCopilotコードレビュー機能や、自律型開発エージェントを構築するスタートアップの新興ツールと直接競合します。重要な差別化要因は深さです——Anthropicのマルチエージェントアプローチは軽量な代替手段より遅くコストが高いですが、表面的なスキャンでは見逃される問題を検出します。</p>

<h2>料金と利用可能状況</h2>

<p>Code ReviewはClaude for TeamsおよびClaude for Enterpriseの顧客に提供されています。PR Stewardと自動承認はベータ版です。Code Reviewはトークン使用量に基づいて課金され、PRのサイズに応じて通常1レビューあたり15〜25ドルです。</p>

<p>Claude Codeのラン・レート収益はリリース以来25億ドルを超えており、Anthropicの開発者ツールの企業での強力な採用を示しています。</p>
