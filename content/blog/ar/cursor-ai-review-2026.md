<h2>ماذا يفعل Cursor</h2>
<p>Cursor هو محرر كود أصلي بالذكاء الاصطناعي مبني كنسخة متفرعة (fork) من VS Code. فهو لا يضيف الذكاء الاصطناعي إلى محرر — بل يعيد بناء تجربة التحرير حوله. كل جزء من سير العمل مدرك للذكاء الاصطناعي: يتنبأ الإكمال التلقائي بتسلسلات متعددة الأسطر بناءً على أنماط مشروعك، وتفهم الدردشة قاعدة الكود بأكملها، ويحرر Composer ملفات متعددة في آن واحد من أوصاف باللغة الطبيعية. وفي 2026، أصبح Cursor المحرر الذي يوصي به المطورون المحترفون أكثر من غيره.</p>

<h2>ما اختبرناه</h2>
<p>استخدمنا Cursor يوميًا لمدة ستة أسابيع على مشاريع حقيقية: تطبيق SaaS بـ Next.js وخط بيانات بـ Python وإصلاح أخطاء عبر مستودعات متعددة وتنفيذ ميزات جديدة من أوصاف بلغة إنجليزية بسيطة. وقارنّا جودة المخرجات بـ GitHub Copilot وClaude Code والبرمجة اليدوية.</p>

<h2>ما الذي تغيّر منذ سبتمبر 2026</h2>
<p>ثلاثة تحديثات كبيرة تجعل Cursor أقدر بكثير مما كان عليه عند مراجعتنا الأولى له:</p>
<ul>
  <li><strong>Composer 1.5:</strong> نموذج Cursor الوكيلي الخاص، أُطلق في فبراير 2026. يتعامل مع التعديلات متعددة الملفات بوعي أفضل بالسياق وهلوسات أقل من الإصدار السابق.</li>
  <li><strong>وضع الوكيل:</strong> يخطط الذكاء الاصطناعي نهجًا متعدد الخطوات ويحرر الملفات وينفذ الأوامر ويعالج الأخطاء ويكرر باستقلالية. تصف ما تريد بناءه، فيبنيه Cursor — مشغّلًا الاختبارات ومصلحًا المشكلات أثناء ذلك.</li>
  <li><strong>تحول التسعير:</strong> يقدم Cursor الآن باقتي Plus ($8/شهر) وPremium ($30/شهر). وانتقل GitHub Copilot إلى فوترة قائمة على الاستخدام برصيد الذكاء الاصطناعي في يونيو 2026، مما يغير حسابات المنافسة.</li>
</ul>

<h2>ما ينجح جيدًا</h2>
<ul>
  <li><strong>فهرسة قاعدة الكود:</strong> يفهرس Cursor مشروعك بالكامل — كل ملف وكل استيراد وكل تعريف نوع. وعندما تطلب منه تنفيذ ميزة، يعرف بنية مشروعك وتسمياتك وأنماطك القائمة. هذه أكبر ميزة له على GitHub Copilot الذي يتعامل مع كل اقتراح بشكل أكثر استقلالية. والفرق واضح فورًا عند العمل على مشاريع تضم أكثر من بضعة ملفات.</li>
  <li><strong>تحرير Composer متعدد الملفات:</strong> صِف ما تريده بلغة إنجليزية بسيطة وسينشئ Composer ملفات في مشروعك ويعدّلها ويربطها. «أضف مصادقة المستخدم بالبريد الإلكتروني وكلمة المرور، وأنشئ صفحتي تسجيل الدخول والتسجيل، واربطهما بقاعدة البيانات الحالية» — يتعامل Composer مع هذا كمهمة متماسكة لا كتعديلات منفصلة غير مترابطة. وفي إعادة الهيكلة أو إضافة ميزات تمس ملفات متعددة، يوفر هذا ساعات.</li>
  <li><strong>وضع الوكيل:</strong> هذا Composer مدفوعًا إلى أبعد. يخطط الوكيل نهجه وينفذ الخطوات ويشغّل اختباراتك ويقرأ رسائل الخطأ ويكرر. سلّمه تقرير خطأ مع تتبع للمكدس (stack trace) وسيحدد المشكلة ويقترح إصلاحًا وينفذه ويشغّل الاختبارات ويعود إليك بالتقرير. والاستقلالية مفيدة فعلًا للمهام التي كنت ستفوضها لمطور مبتدئ.</li>
  <li><strong>إكمال Tab:</strong> الإكمال التلقائي مدرك للسياق بطريقة تجعلك تشعر أن الذكاء الاصطناعي يفهم ما تبنيه لا ما تكتبه فحسب. يتنبأ بتسلسلات متعددة الأسطر — أجسام دوال كاملة وحالات اختبار ومعالجات API — بناءً على الأنماط في مشروعك. وبلغ معدل القبول في اختبارنا نحو 45%، ارتفاعًا من 40% في مراجعتنا لسبتمبر.</li>
  <li><strong>بيئة مألوفة:</strong> بُني على VS Code، فتنتقل كل إضافة وسمة واختصار لوحة مفاتيح وإعداد. والتحول من VS Code إلى Cursor يستغرق أقل من 5 دقائق. وإذا كنت تستخدم VS Code أصلًا، فلا منحنى تعلم للمحرر نفسه — فقط لميزات الذكاء الاصطناعي.</li>
</ul>

<h2>ما يقصّر فيه</h2>
<ul>
  <li><strong>حدود الاستخدام:</strong> قد تقيّد حدود الطلبات في Premium المستخدمين الكثيفين. وخلال اندفاعات التطوير المكثفة — تصحيح مشكلة معقدة أو بناء وحدة ميزة جديدة — من الممكن بلوغ السقف في يوم واحد. ما زال بإمكانك البرمجة، لكن دون ميزات الذكاء الاصطناعي المميزة حتى تُعاد تهيئة الحد. وهذه أكثر شكوى شيوعًا من المستخدمين المتمرسين لـ Cursor.</li>
  <li><strong>VS Code فقط:</strong> إذا كان فريقك يستخدم JetBrains (IntelliJ وPyCharm وWebStorm) أو Neovim أو Xcode، فإن Cursor ليس خيارًا. وهذا هو السبب الرئيسي في احتفاظ GitHub Copilot بحصة سوقية 68% — فهو يعمل في كل مكان.</li>
  <li><strong>هلوسات عرضية:</strong> يولّد وضع الوكيل أحيانًا كودًا يبدو صحيحًا لكن فيه أخطاء دقيقة — مسار استيراد خاطئ أو دالة API خاطئة أو عدم تطابق أنواع يلتقطه TypeScript لكن لا تلتقطه لغة ديناميكية. ويتطلب الكود المولَّد مراجعة، خاصة للمنطق المعقد.</li>
  <li><strong>المستودعات الأحادية الضخمة:</strong> يتدهور الأداء مع قواعد الكود الكبيرة جدًا. تتباطأ الفهرسة وتمتلئ نوافذ السياق وتقل ملاءمة الاقتراحات. وللمستودعات الأحادية ذات ملايين الأسطر، التجربة أسوأ بوضوح منها في المشاريع الأصغر.</li>
  <li><strong>التوثيق:</strong> التوثيق الرسمي لـ Cursor شحيح. معظم النصائح وسير العمل وأفضل الممارسات تأتي من المجتمع — مقاطع YouTube وسلاسل Twitter والمقالات. تطلق الشركة الميزات أسرع مما توثقها.</li>
</ul>
